# 放課後ボード（シンプル版）

HTMLファイル1つだけで動作する高校生向け掲示板の静的デモです。

## GitHubへアップロード
1. GitHubで新しいリポジトリを作成（例：`houkago-board`）。
2. `index.html` をリポジトリのルートにアップロード。
3. Azure Static Web AppsでGitHubリポジトリを接続し、アプリの場所を `/`、APIの場所を空欄、出力先を `/`（または空欄）にしてデプロイします。

## 注意
投稿はブラウザの `localStorage` に保存されます。投稿者本人が同じブラウザで開いた場合に表示され、他の利用者と共有されません。全利用者で投稿を共有するには、データベースとAPIなどのバックエンドが必要です。
